The searching interface has the following features:
(1) It contains an input box to upload an image/description text (Formulation); 1分
(2) Users can preview the query in the searching window (Formulation);1分
(3) It has a search button (Initiation); 1分
(4) Provide an overview of the results (e.g. the total number of results) (Review); 1分
(5) Allow changing search parameters (e.g. change the number of returned images) when reviewing results (Refinement); 1分
(6) Users can take some actions, e.g. add selected images to a favorite list or download (Use); 1分

图像搜索功能
(1) 以文字搜索图像：用户能够使用文字进行图像搜索，并得到按相似度排序的结果（2分）
(2) 以图像搜索图像：用户能够使用图像进行图像搜索，并得到按相似度排序的结果（2分）
(3) 用户可以使用（如下载或者收藏）检索到的图片（1分）
