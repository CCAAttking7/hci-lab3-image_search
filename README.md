# 🔍 Five-Stage Visual Search System (基于五段式搜索模型的视觉检索系统)

这是一个严格基于 **HCI (人机交互) 五段式搜索框架** 构建的智能语义图像检索界面，底层由 CLIP 与 Upstash Vector DB 强力驱动。

## 🚀 执行工作流与架构设计

### 1. 数据处理管道 (从 CPU 到 GPU 的演进)
我们起初计划在本地 CPU 环境中对图像集进行编码。然而，针对数千张图像运行 **CLIP ViT-B/32** 模型的计算量极大（本地 CPU 负载直接拉满，几近“冒烟” 🔥）。

为了保障性能并构建充实的向量特征库，**整个向量化管道被果断迁移至 Kaggle 的 GPU 环境中执行**。
- 我们在 Kaggle 环境 (双 T4 GPU) 中直接执行了 `src/full_on_GPU.py` 脚本。
- 在短时间内，我们成功下载、编码并向云端向量数据库 (Upstash) 中推送了来自 `MS-COCO 2017 Validation` 数据集的 **5000+** 图像检索向量。

### 2. 检索架构
- **特征编码：** 用户输入文本或上传图片后，本地应用调用 `OpenAI CLIP` 将查询实时映射为 512 维的向量。
- **搜索引擎：** 随后利用余弦相似度 (Cosine Similarity) 快速从远端 `Upstash Vector DB` 查询匹配结果。
- **用户交互：** 基于 Gradio 深入定制前端界面，提供流畅无缝的人机交互体验。

## 🎯 评分标准 (HCI Rubrics) 对齐说明

本项目在交互设计上完美对齐并实现了五段式检索模型的十一项设计要求，确保满分呈现：

### I. Formulation（表达阶段 - 2分）
* **支持文本与图像搜索 (1分)：** 前端提供了专门的 Tab 切换，既支持文本描述 (`gr.Textbox()`)，也支持图片上传 (`gr.Image()`) 作为输入。
* **搜索预览 (1分)：** 右侧拥有实时的预览面板模块。当输入中文时会预览翻译后的实际查询，上传图片时保留图片缩略映射，保证“What you see is what you query”。
* *（超额奖励 / Bonus）：* 集成了 **Bing Autocomplete API** 进行动态联想词推荐。并且内置了中翻英模块，用户可以直接用中文进行无缝语义表达。

### II. Initiation & Review（发起与审查阶段 - 2分）
* **一键发起 (1分)：** 高度显著的 **“Search” (搜索)** 按钮，且在文本框下深度支持回车 (Enter) 热键潜意识发起。
* **全局结果概览 (1分)：** 在侧边栏和结果栏中，系统会准确告知用户“实际检索到了多少条结果”及“本轮消耗时间”（如：`Found 16 results · Query time: 0.45s`）。

### III. Refinement（调整与求精阶段 - 1分）
* **动态参数控制 (1分)：** 我们专门设计了非阻塞式 (Non-blocking) 的参数调优机制。用户可以直接滑动 `Top-K（最大返回数）` 以及 `Min Similarity Score（最小相似度阈值）`。**图像会自动根据新参数静默重裁刷新，不需要重新点击搜索按钮**。

### IV. Use（利用与操作阶段 - 1分）
* **收藏与本地下载 (1分)：** 当用户点击单张图片后，会在预览窗生成一个爱心 `❤️ Saved` / `♡ Save to favorites` 按钮。收藏的图片可以在专门的收藏域统一管理打包 `.ZIP` 立即下载到本地硬盘。

### V. 核心检索能力得分（5分）
* **以文搜图 (2分)：** 基于文本向量实现高度语义相关的图像召回排序。
* **以图搜图 (2分)：** 基于图像视觉与语义特征，召回最相似的同类图像。
* **结果实用性机制 (1分)：** 检索出的结果无缝流向 Favorites 与下载池中，将检索与实用完美闭环。

## 💻 本地运行指南

1. **配置环境：**
   本项目使用极速的 `uv` 工具管理，推荐 Python 3.12+ 运行环境：
   ```bash
   uv sync
   # 或者直接通过您现有的虚拟环境管理器加载依赖
   ```

2. **补全凭证环境变量：**
   为了安全，云端数据库凭证已改为从环境变量获取，请在命令行中（或利用 `.env` 文件）添加：
   ```env
   UPSTASH_VECTOR_REST_URL=您的_upstash_url
   UPSTASH_VECTOR_REST_TOKEN=您的_upstash_token
   ```

3. **启动应用：**
   ```bash
   uv run python src/app.py
   # 若配置了系统代理可能端口会被占用，可按需添加： NO_PROXY=localhost uv run python src/app.py
   ```
   随后在任意浏览器中打开 `http://localhost:7860` 即可沉浸体验！
